# Personal Brand Projects

Planning and experiments for a practical technology personal brand on Instagram for ambitious Iranians:
**discover opportunities, understand technology, build things.**

## Contents

- [`strategy/brand-interview.md`](strategy/brand-interview.md): positioning, audience, voice and long-term direction, from the brand interview.
- [`experiments/01-content-territory-test/`](experiments/01-content-territory-test/): first 4-week experiment.
  - [`plan.md`](experiments/01-content-territory-test/plan.md): hypotheses, fixed variables, schedule, metrics, decision rules.
  - [`posts.md`](experiments/01-content-territory-test/posts.md): the 20 test posts (hook, outline, closing question).
  - [`tracker.csv`](experiments/01-content-territory-test/tracker.csv): fill in each post's numbers 7 days after posting (import into Google Sheets).

## Tracker rates

Add these as columns in your spreadsheet:

- **Share + save rate** = (shares + saves) / reach  ← primary
- **Follow rate** = follows / reach
- **Conversation rate** = (comments + dms) / reach
