# Assets for the live portfolio

Everything on the page must be real. Drop files here using the names below, and Claude will compress them and wire them in. Tick each box as it lands.

## Recording specs (all products)
- **Phone screen recordings**, portrait, the phone's native resolution, 30 fps, no audio needed. Use the phone's own screen recorder, or for a web app use Chrome DevTools device mode at 390×844.
- **15–25 seconds each**, one clear action per clip, no hunting around. Rehearse once, then record. Start and end on a calm screen, because the clip loops.
- **Privacy:** use a demo or test account. No real user names, phone numbers, emails, balances, wallet addresses, order IDs or chat contents. If something slips in, say so and Claude will blur it, but clean recordings are better.
- **Stills:** for each clip, also 1–2 PNG screenshots of its best frame (used as the poster while the video loads on slow connections).
- **Rights:** only send what you're allowed to publish. Confirm per product in the last section.
